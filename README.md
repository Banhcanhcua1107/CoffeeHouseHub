A modern and stylish coffee shop website, built with **ReactJS + Vite**, styled using **Tailwind CSS**.  
Live Demo: **[CoffeeHouseHub](https://coffeehousehub.vercel.app/)**

---

## 📝 About

**CoffeeHouseHub** is a web application that allows users to browse, explore, and order from our coffee menu online.  
The site is designed for **speed, scalability, and seamless user experience**.

### 🔑 Key Features
- 🎨 Modern, responsive UI with [Tailwind CSS](https://tailwindcss.com/)
- ⚡ Fast development & build time with [Vite](https://vitejs.dev/)
- 🚀 Frontend deployed on [Vercel](https://vercel.com/) with CI/CD
- 🌐 Backend API hosted on [Railway](https://railway.app/)
- 🧩 Modular, clean code with **ReactJS**

---

## 🖥️ Tech Stack

| Technology    | Description                             |
| ------------- | --------------------------------------- |
| **ReactJS**   | Frontend framework                      |
| **Vite**      | Next-generation frontend tooling        |
| **Tailwind CSS** | Utility-first CSS framework          |
| **Vercel**    | Frontend hosting & deployment           |
| **Railway**   | Backend hosting (Node.js/Express)       |
| **GitHub**    | Source code management                  |
